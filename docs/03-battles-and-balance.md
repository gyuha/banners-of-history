# 20개 전투와 병종 설계

## 증거의 범위

원작은 [Song of Ashes — Historical Battles Demo](https://hank1105.itch.io/heroes-battlefield-demo)다. ego-lite에서 전투 20개를 각각 선택해 브리핑을 수집한 `docs/evidence/original-all-battles.json`이 이 문서의 핵심 원자료다. 초기 기록 `original-battles.txt`와 `original-heroic.txt`는 1번·11번의 상세만 담지만, 후속 수집으로 **20개 모두의 설명·병력표·지형·전술 조언·승리 조건**을 확인했다. 원작 전투를 20개 전부 끝까지 플레이했다는 뜻은 아니다. 실제 실행 관찰은 별도 `original-battle-runtime.txt`, `original-controls.txt`와 전투 화면 증거를 따른다.

아래 원작 병력은 **원작 UI의 게임용 수치**다. 역사적 실제 인원이나 이번 게임에서 소환되는 인원과 같지 않다. 전술·승리 조건은 한국어로 요약했으며 설명 글·코드·이미지·음원을 원작에서 옮기지 않았다. 역사 배경은 원작의 참고 사료를 확인할 출발점이지 그 사료를 교차 검증한 학술 결론이 아니다.

## 재구성 데이터와 공통 판정

`src/battles.js`는 `BATTLES` 배열과 `TROOPS` 객체를 내보낸다. `id`는 1–20, `mode`는 전술 `tactical`/영웅 `heroic`, `title`은 새 부제, `name/year/region`은 표시 정보다. `allies/enemies/commander/enemyCommander`가 진영을, `terrain`이 지형 유형을, `intro/tactic/objective`가 한국어 문구를 담는다. `duration`은 초, `allyCount/enemyCount`는 실제 시뮬레이션 병력, `victory`는 판정 분류, `difficulty/accent/reward`는 난도·색·기념 칭호다.

이번 버전은 공용 판정과 시나리오별 복합 목표를 함께 쓴다. 아래 내용은 `src/engine.js`의 `getObjectiveStatus()`, `updateScenarioState()`, `updateBattle()`를 읽어 대조한 구현 기록이다. 실제 브라우저 검증 여부는 검증 보고서를 별도로 따른다. 원작과 완전히 동일한 공식이나 지형이라는 뜻은 아니다.

| 판정 | 이번 버전에서의 조건 |
|---|---|
| `hold` | 아군 거점 두 곳 이상을 연속 40초 점유. 두 곳 미만이면 누적 초기화. 적 전멸 또는 제한 시간 종료 시 거점 하나 이상 확보도 승리 |
| `capture` | 공용 거점 세 곳을 모두 아군 소유로 전환 |
| 기본 `rout` | 적 생존 수가 0이 되면 승리 |
| 13·16 `raid-return` | 좌우 두 습격 거점을 한 번씩 확보한 기록을 만든 뒤 지휘관이 남쪽 아군 본진(z>31)으로 귀환 |
| 14·19 `commander-rout` | 이름 있는 적 지휘관을 제압하고 최초 적 개체의 최소 30%를 격파 |
| 15 `escort` | 중앙 거점을 확보하면 피난민·부상병 두 명 생성, 둘 모두를 남쪽 아군 본진으로 호송. 한 명이라도 사망하면 패배 |
| 17·20 `strength-rout` | 생존 적의 남은 체력 비율 합을 최초 적 개체 수로 나눈 유효 전력을 20% 이하로 낮춤 |

시나리오별 판정은 전투 ID로 공용 `victory` 값을 덮어쓴다. 따라서 13–20 일부 객체의 `victory` 필드만 보고 실제 승리 조건을 판단해서는 안 된다. 모든 전투는 약 3분으로 압축하고 지휘관 사망은 패배다. 시간 제한은 실제 역사상의 지속 시간과 관계없다.

원작 복합 목표의 중심 구조는 13/16 귀환, 14/19 지휘관과 30%, 15 호송, 17/20 유효 전력으로 반영했다. 다음 세부 차이는 남는다. 원작 장판의 감부인·어린 후계자 대신 새 피난민·부상병을 사용하고 중앙 점령으로 합류를 시작한다. 귀환 방향은 원작의 서쪽 대신 새 지도 남쪽이다. 원작 ‘패주’는 이번 버전에서 격파 개체 비율로 계산하며 사기와 탈영을 합산한 동일 수식이라고 볼 수 없다. 원작 20% **미만**과 이번 20% **이하**도 경계가 다르다. 정군산·정형·관도·북벌의 원작 동시 점유 유지 시간과 이번 공용 세 거점 점령, 원작 9/10분 방어와 이번 40초는 계속 축약된 설계다.

## 원작과 이번 버전의 전투별 대조

병종 괄호의 정예 분류를 한국어 공용 명칭으로 옮겼다. 같은 분류라도 원작 부대 이름이 다른 별개 부대라면 인원을 합치지 않고 각각 적었다. 원문의 상세 역사 진영명은 JSON을 참조한다.

**원작 관찰 · 역사 전술**

- 추천 진영 병력 **6,000명**: 정예 장창병 2,400명 / 중장 방패병 1,600명 / 정예 도끼병 1,200명 / 장궁병 800명.

- 지형: 긴 능선·완만한 경사·측면길.

- 전술 요약: 북·남 깃발 전방의 창병을 정지시켜 방어 태세를 만들고, 방패로 화살을 받는다. 도끼병은 뒤에 남기며, 궁병은 능선 뒤에 보호한다. 기병을 따라 고지를 버리지 않는다.

**이번 버전 · 능선 위 마지막 방패**

## 역사 표현과 후속 개발 주의점

- 원작의 역사 설명은 거록에서 왕리의 패배와 장한의 나중 항복을 분리하고, 헤이스팅스에서 해럴드의 정확한 죽음 방식에 논쟁이 있음을 밝힌다. 재구성도 불확실한 일화를 확정적으로 쓰지 않는다.
- 칸나이의 로마 지휘는 파울루스와 바로, 스털링은 월리스와 머리, 마릉은 전기와 손빈, 정형은 한신과 장이의 공동 지휘 구조를 원작이 표시한다. 이번 한 줄 지휘관 필드는 대표 인물로 축약했다.
- 장판 원작의 적 지휘관은 조순이다. 이번 데이터의 조조는 추격군의 상위 진영 대표로 축약한 선택이다. 진경지 북벌의 원작 상대는 원천목, 하서는 하서 지역 왕들로 표시된다.
- 원작의 ‘유효 전력’은 UI 표현이다. 사기·격파·패주가 어떤 수식으로 합산되는지는 완전한 구현 자료가 없으므로 불명확하다.
- 원작 전술 모드의 부장별 전선, 압박 시 후퇴 지점과 재공격 설명은 이번 병종별 명령보다 세밀하다. 같은 AI가 구현되었다고 가정하지 않는다.
- `BATTLES` 20개와 ID 연속성, 전술·영웅 각 10개, 인원 범위·지형·승리 열거값은 Node로 검사했다. 데이터 유효성 검사는 전투 20개를 플레이로 완주한 검증이 아니다.
- 후속 개발은 복합 목표의 UI·저장·업적 연결과 실패 분기를 먼저 회귀 검증하고, 정군산/정형/관도/북벌의 서로 다른 거점 수·동시 유지 시간을 분리하면 된다. 장판의 개별 탐색·합류와 원작의 사기·패주 체계는 별도 확장 과제다.
