## 증거 폴더

`evidence/`에 원작 공개 페이지 텍스트, 실제 메뉴/전투 스크린샷, 20개 브리핑, 각 전투의 역사 참고 URL, REA 요약 JSON과 구현 검증 기록을 보관한다. 원작에서 수집한 파일은 조사용이며 실행 제품의 `public/`이나 빌드에 포함하지 않는다.

‘직접 관찰’은 해당 메뉴나 화면을 실제 Ego Lite에서 열어 확인했다는 뜻이다. ‘정적 분석’은 실행을 증명하지 않는다. ‘재구성 설계’는 이번 게임을 위해 새로 선택한 수치와 규칙이다. 원작과 동일하지 않은 부분을 동일하다고 가정하며 이후 기능을 개발하지 않는다.
