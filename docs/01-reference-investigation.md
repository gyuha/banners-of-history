# 원작 조사와 근거 장부

## 대상과 조사 방식

대상은 JUMO GAMES의 [Song of Ashes — Historical Battles Demo 배포 페이지](https://hank1105.itch.io/heroes-battlefield-demo)다. 원작은 실시간 지휘관 액션과 부대 지휘를 결합한 브라우저 게임이다. 전술 역사 전투 10개와 영웅 무쌍 전투 10개, 지휘관·군단·군기 사용자화, 도감과 전투별 업적이 중심 구조다.

조사는 사용자가 지정한 **ego-lite**에서 실제 배포 페이지와 게임 화면을 열고 메뉴를 조작해 진행했다. 20개 전투 브리핑을 각각 선택해 DOM의 읽을 수 있는 텍스트를 보관했고 실제 거록 전투의 HUD·일시정지·도감·장비·지휘관 화면도 확인했다. 화면에서 기능을 보았다는 사실, 설명문이 기능을 약속했다는 사실, 전투에서 작동을 끝까지 시험했다는 사실은 구분한다.

정적 조사는 배포된 공개 시작 파일의 제한된 범위에서 REA로 수행했다. 원작 전체 게임 소스 복원이나 모든 전투의 실전 검증은 수행하지 않았다. 재구성은 별도로 작성한 Three.js 코드·한국어 문구·새 자산을 사용한다.

## 게임 루프와 화면 구조

배포 페이지에서 실행하면 지휘관과 군단을 만든 뒤 전장 목록에 진입한다. 메뉴 상단에는 게임 정체성, 현재 군단·지휘관, 도감·업적·군기·설정 진입이 있다. 전투는 두 모드로 나뉘며 선택한 항목 옆에 전장 지도, 양군 이름과 부대별 병력, 지휘관, 지형, 역사 배경, 조언과 목표를 보여 준다. 전투 준비 단계에서 장비를 바꾸고 출전한다. (E01–E05, E10–E11)

전술 모드에는 추천 진영 외에 반대편 군대를 지휘하는 선택도 있다. 전선별 임무와 부장의 행동이 별도로 설명되며, 플레이어가 부대를 선택하면 다른 전선을 맡았다가 부장에게 돌려줄 수 있다는 안내가 있다. 예컨대 헤이스팅스는 북·남 능선, 칸나이는 중앙·남북 기병익, 이소스는 중앙 하상·북쪽 산기슭·남쪽 해안으로 분할된다. 단순한 전군 AI 한 종류보다 세밀한 지휘 구조다. (E03, E05)

영웅 모드는 지휘관이 선택한 외모와 이름을 유지하면서 해당 역사 영웅의 능력을 맡는다. 브리핑은 체력 10,000, 피해 감소 60%, 전투 이탈 시 회복과 소수 정예 근위대를 명시한다. 거록 실제 HUD에서 체력 10,000/10,000과 초군 600명·적 18,000명을 확인했다. 다른 영웅의 모든 피해·회복 공식을 실전에서 측정한 것은 아니다. (E04–E07)

브리핑의 역사 설명은 시대·교전 군대·전쟁 원인·전투 경과·결과로 나뉜다. 역사적 승자대로만 끝내야 하는 구조는 아니며 다른 목표와 진영 선택을 게임 규칙으로 제공한다. 설명에 나타난 고대 인원·영웅 능력은 역사 수치를 확정하는 자료가 아니다. 전투별 전체 비교는 [03-battles-and-balance.md](03-battles-and-balance.md)에 정리했다.

## 조작과 전투 HUD

실제 화면에 표시된 기본 조작과 현재 상태는 다음과 같다. 아래 키는 원작 화면의 안내를 조사한 것으로 이번 재구성의 키 배치와 일부 다를 수 있다. (E07–E08)

| WASD | 지휘관 이동 |

| 확대 조절 | HUD에 확대 조절 항목 존재 |

| 전술 지도 | 별도 진입과 화면 확장 표시 |

거록 HUD는 점령 진영 0/3, 남은 약 12분, 전투 경과 시간, 양군 병력, 개인 격파 수, 체력, 무쌍 게이지와 연속 타격 수를 함께 표시한다. 출전 직후 수집된 기록에서 약 10–16초 경과, 근위대 4부대의 이동·교전 상태를 볼 수 있다. 원작의 정확한 카메라 거리 범위·휠 감도·주요 사건 자동 줌의 존재나 전환식은 이 자료만으로 확정할 수 없다. 사용자가 요청한 사건별 자동 확대·축소는 재구성의 별도 설계다.

무쌍 안내는 밀집한 적에게 기술 회전을 2–3회 성공시키면 게이지를 모을 수 있고, 빗맞힘은 기여하지 않으며 같은 기술에서 같은 대상을 중복 적중해도 한 번으로 센다고 설명한다. 이 문구는 게이지의 내부 공식까지 알려 주지는 않는다. (E05)

## 병종·지형·도감

도감 화면에는 병종, 무기·기술, 지형, 전투, 업적의 다섯 묶음이 있다. 현재 전투의 병종만 보기, 고급 병종, 전체 병종 필터가 관찰됐다. 병종은 기본 1단계에서 정예 근위 3단계까지 구별되고 같은 시대 부대 이름과 공용 전투 분류를 함께 보여 준다. (E09)

직접 선택된 기본 창병은 병사당 체력 145, 타격 피해 58, 피해 감소 17%, 근접 거리 55를 표시했다. 정지 방어 시 정면 기병에 강하고 이동 중이나 측후방 근접 공격에 약하다는 설명도 있었다. 이는 도감 표시의 관찰이며 실제 공격 주기·단위 환산·연산 순서를 복원한 것이 아니다.

전체 브리핑의 병종표에는 창·방패·검·도끼·충격 보병, 여러 등급의 장궁·쇠뇌, 경기병·정예 유격 기병·충격 기병·중장 기병이 반복 등장한다. 이번 공용 6병종과 원작의 단계별 상세 수치는 동일하지 않다. (E05, E09)

지형 설명은 오르막 감속, 완만한 내리막의 돌격 보조, 능선의 직사 차단, 낮은 능선을 넘는 곡사 화살을 안내한다. 전투별 다리·마른 길·습지·숲·보급로·고개와 우회로를 실제 AI가 어떻게 판정하는지는 모든 경로를 시험하지 않았다. (E05)

## 지휘관·문장·장비

지휘관 제작 화면에서 개인 이름과 군단 이름을 수정할 수 있다. 초상은 총 40개, 남성 24개·여성 16개 필터가 표시되고 이름표와 전투 체력 패널에 사용된다고 안내한다. 장비 외모와 초상은 별도 선택이다. (E01, E10)

문장은 단색·수직/수평/대각 분할·사분할·십자/역십자 계열·가로/세로 줄무늬·체크 등 바탕 분할, 사자·독수리·용·기린·유니콘·짐승 머리·꽃·별·달·태양·탑·왕관·칼·열쇠·닻 등 도안, 십자·갈매기·띠·테두리 등의 도형을 조합한다. 한·초·진·조·제·위·촉·오·당·송·금·양 등 역사 진영과 성씨 한자 문양도 제공한다. 주 바탕·보조 바탕·도형·문양의 네 색을 개별 변경하고 정해진 팔레트나 무작위를 선택한다. (E10)

원작 소개는 장비 8세트를 혼합한다고 설명한다. 실제 무기고는 검·방패, 대검, 장궁, 쇠뇌, 기병창, 지팡이의 여섯 무기 항목과 갑옷/투구 각 8항목, 망토 3항목, 도보 또는 말 3색, 마갑 3항목을 표시했다. 갑옷·투구는 검방패 계열 3단계, 대검 계열 3단계, 중기병·경기병 정예 외형이 나열된다. 무기고 캐릭터를 좌우 회전할 수도 있다. (E01, E11)

장비의 같은 무기 유형 안에서는 외형에 따른 수치 우위가 없고, 무기 유형이 동작·기술을 결정하며 체력·피해·방어는 전투 규칙이 정한다고 명시한다. 재화나 해금 없이 조합할 수 있고 장비 외형은 전투 사이에 유지된다는 안내다. 실제 장착·장비 취소 버튼과 외형별 모든 모션은 전체 조합으로 시험하지 않았다. (E11)

## 설정·업적·저장

일시정지 설정에는 화면 흔들림, 효과 품질(자동/높음/중간/낮음), 피해 숫자(전체/치명타만/끄기), UI 모드(자동/데스크톱/휴대전화 가로), 언어(시스템/영어/번체 중국어)가 관찰됐다. 원작 소개는 가로 휴대전화 터치 입력을 지원하고 첫 실행에 지원 브라우저 언어를 따르며 다른 언어는 영어로 시작한다고 설명한다. **한국어는 관찰된 원작 언어 옵션에 없다.** 이번 전면 한국어 UI는 사용자 요청에 따른 새 구성이다. (E01, E08)

원작은 전투당 서로 다른 업적 5개, 총 100개와 동·은·금 메달 및 해금 힌트를 소개한다. 목록 전부의 개별 조건이나 메달 산정식을 조사한 것은 아니다. 이번 게임에서 같은 개수의 기록을 제공하더라도 원작의 업적 조건과 같다는 뜻은 아니다. (E01, E03–E05)

원작 설명은 현재 브라우저에 진행을 저장한다고 한다. 실제 저장 스키마·키·용량·스키마 마이그레이션·기기 간 동기화는 분석하지 않았다. 계정이나 서버 저장이 있다는 증거는 없다. 브라우저 저장이라는 소개만으로 원작의 로컬 저장 구현 방식을 확정하지 않는다. (E01)
